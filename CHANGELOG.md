# Changelog

## postqube-0.2.0-beta.2

- Ideas reuses the native sidebar/header, theme toggle, notifications and actual
  design tokens/font. Organizing columns minimize independently.
- Continuous note editor replaces separate block fields. Task circles insert at
  the saved cursor position, with plain-text paste, line preservation and undo.
- Existing block notes remain readable without a destructive data migration.


## postqube-0.2.0-beta.1 — 2026-10-31

Adds Ideas: shared workspace folders → sections → pages → text/task editor,
autosave, optimistic revision checks, tab-local draft recovery and restorable trash.
Reuses native Postiz authentication and current workspace membership. A separate
non-root Node/SQLite service keeps the official Postiz image untouched. Includes
workspace isolation/conflict/backup/API tests and an operational backup guide.


## postqube-0.1.0-beta.1 — 2026-10-31

First documented public beta, based on Postiz v2.25.3. Adds Postqube presentation
source, real desktop/mobile screenshots, operator/developer/user guides, source
notices, public documentation pages, deployment templates and release validation.
Existing X connection/API verified in the test deployment. Instagram pending Meta
account setup; AI/email/billing unconfigured. No successful live publishing test is
claimed for this release. Public commercial launch is not yet approved.
