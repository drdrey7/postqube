# Launch checklist

This beta is not ready to accept paying public customers until the blockers below
are resolved. Checking in a checklist is not evidence that a requirement passed.

- [ ] Final domain/operator identity and source/legal links agreed.
- [ ] Meta account restriction resolved, portfolio linked and login compatibility checked.
- [ ] Instagram callback/credentials/tester authorization; image/carousel/Reel/eligible Story tested.
- [ ] Public customer access approved by Meta where required.
- [ ] X live publish/schedule test with approved content and provider spending reviewed.
- [ ] Email delivery, SPF/DKIM/DMARC, reset and invitations tested.
- [ ] Own privacy/terms/deletion procedure reviewed and signup links corrected.
- [ ] Polotno licensed or disabled; dependency/asset and trademark review complete.
- [ ] Full session/permissions/abuse and security checks; no privileged test accounts.
- [ ] Encrypted off-server backups and isolated restore drill complete.
- [ ] Mobile/desktop/auth/calendar/source links checked after changes.
- [ ] Storage/queue/failure monitoring and support process assigned.
- [ ] AI keys/budgets/consent configured only if activating AI.
- [ ] Stripe products/webhooks/lifecycle/tax review complete only if charging users.
- [ ] Source tag/archive and runtime image provenance match the deployment.

Available now: beta signup/calendar, native API and owner administration, public
source/documentation. All other claims must match STATUS.md and tested behavior.
