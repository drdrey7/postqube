# Postqube

Your content. Your next move.

An independent open-source social publishing workspace, based on Postiz.
Public beta. X is connected in the test deployment; Instagram setup is pending.
AI, email and billing require separate configuration. This site is documentation,
not a claim that the commercial launch checklist is complete.

![Desktop calendar](assets/calendar-desktop.png)

Read Getting started, User guide and Status first. Operators should continue with
Deployment, Operations and Launch checklist. Developers can inspect the complete
source on GitHub and follow UPSTREAM.md to understand the changes.
