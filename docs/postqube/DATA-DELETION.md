# Data deletion preparation

DRAFT REQUIREMENTS — the full operator procedure is not yet published or verified.

The native user endpoint supports account deletion, but this release has not
verified the complete retention/export/media/backup lifecycle. Before launch:
verify authenticated user deletion and shared-workspace implications in staging;
disconnect/revoke provider authorization; define content/media cleanup and backup
expiry; document legally required retention and a real support contact. Published
social posts may remain on the social network; deletion from Postqube is not a
promise to remove them there. Implement any Meta data-deletion callback/instructions
required by the approved app and verify them before public customer access.
