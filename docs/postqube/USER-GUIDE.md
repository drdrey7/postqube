# User guide

## Calendar and posting

Use Day, Week, Month or List. Default posting slots are 09:20, 14:10 and 19:00 in
the timezone used when a channel is connected; displayed times depend on timezone.
These are suggested slots, not posts. Change them from the channel menu → Edit
Time Slots. A custom publication can use its own date/time.

## Settings

/settings → Global Settings → Date Metrics → 24 hours changes the AM/PM display.
This preference is stored per browser. Select your timezone separately and check
summer/winter time. Changing language alone may not change time format.

/settings?tab=teams manages workspace membership. Invitations require email delivery.
/settings?tab=agents exposes native API/agent configuration. Never share API keys
in screenshots or public issues. Groups, signatures, saved sets and webhooks are
native surfaces; enable external integrations only when needed.

## Administration

/admin/stats and /admin/errors require a global superadministrator. An ordinary
workspace admin is different. The native statistics show publishing activity;
there is no complete signup directory or unified provider-cost dashboard.

## AI

An external assistant can prepare copy and use the authorized native API. The
in-app assistant still requires its own provider key. Do not assume a chat
subscription supplies API credits. The legacy visual generator is additionally
conditioned on billed mode in this version; do not enable Stripe merely to expose it.
