# Frequently asked questions

## Do we need the final domain now?

No. Repository/docs can be prepared now. Set the final domain before public launch
and provider review to avoid callbacks, media and legal links changing afterwards.
The current address remains a test deployment.

## Is this independent of Postiz?

Postqube operates independently but is derived from Postiz, with AGPL obligations
and preserved attribution. It is not exclusively owned original upstream code.

## Is it all free?

Source access is free under its license. VPS, media storage, API usage, optional AI,
commercial SDKs and payment processing can cost money. There is no unified native
cost dashboard. Do not turn on Stripe merely to unlock a legacy UI button.

## Can I connect a personal Instagram account?

The connected account must be professional. The shared developer app is managed
separately; each customer authorizes their own account.

## Does public source reveal customer data?

No customer records, uploads or production secrets belong in the repository. Public
source includes implementation and sanitized build/configuration information.
